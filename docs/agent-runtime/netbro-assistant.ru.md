# Встроенный ассистент NetBro

NetBro появляется рядом с ReBro после обновления. Выберите **NetBro** для
нового диалога. Выбранный ранее ассистент и существующие диалоги сохраняются.

В профиле включены **Termux**, **Local search** и шесть skills. Модель и
провайдер поиска берутся из общих настроек. Если у модели активен встроенный
поиск, выберите Local в меню поиска чата, как для ReBro.

| Навык | Возможности |
|---|---|
| netbro-bbot | Разведка, presets/modules, scope и events; учтены различия BBOT 2/3 |
| netbro-nmap | Хосты, порты, сервисы, TCP/UDP и привилегии, XML evidence |
| netbro-nuclei | Выбор и валидация templates, rate/concurrency, JSONL и разбор findings |
| netbro-legba | Протоколы, конечные входы для проверки аутентификации, session и partial matches |
| netbro-environment | Проверка версий, диагностика зависимостей, выбор среды установки |
| netbro-workflow | Маршрут исследования, scope, состояния задач, результаты и восстановление |

## Начало работы

1. Настройте [Termux и передачу навыков](../getting-started.md#4-termux-и-файлы-skills).
2. Откройте NetBro и опишите задачу, цели и нужный результат. Например:
   «Проверь готовность Nmap в моём Termux» или
   «Разбери приложенные результаты Nmap и Nuclei и сопоставь находки».
3. Для сканирования задайте конкретные хосты/сеть/URL и ограничения задачи.
   NetBro выбирает нужный инструмент, проверяет его версию и пишет результаты
   в отдельный case. Четыре программы не запускаются автоматически для каждого вопроса.
4. Длительные операции используют обычные Termux jobs с deadline, логами
   и возможностью продолжить после сверки состояния. Уточнения на ходу,
   Stop и полный экспорт Trajectory работают как у других ассистентов.

**В APK входят навыки и helpers.** BBOT, Nmap, Nuclei и Legba не упакованы
в приложение как готовые бинарники и не устанавливаются при выборе профиля.
Зависимости и фактическую работоспособность нужно проверить в той среде,
где инструмент будет запускаться.

Nmap доступен в официальном репозитории Termux. BBOT upstream поддерживает
Linux; его Python/native-зависимости и сборка Legba могут потребовать
подходящего Linux-окружения. Proot сам по себе не даёт привилегий raw sockets,
а Linux ARM64 binary не обязательно совместим с Android.
[Маршруты установки и первичные источники](../../app/src/main/assets/default-skills/netbro-environment/references/install.md).

## Полные пакеты и управление

Шесть пакетов содержат **22 файла** с английскими инструкциями: references, шаблон case,
три Python-скрипта и манифесты. Все файлы доступны в мастерской навыков,
участвуют в импорте/экспорте и передаче в Termux через существующий bridge.
После успешной подготовки агент использует возвращённый skill_root.

| Helper | Что делает |
|---|---|
| preflight.py | Проверяет только version-команды выбранных инструментов; ограничивает время и вывод |
| scope_filter.py | Отбирает host/IP/URL по точным именам, явным wildcard и CIDR, учитывает исключения; без DNS |
| summarize.py | Читает Nmap XML и BBOT/Nuclei/Legba JSONL, считает записи и выдаёт ограниченное превью |

Сводка Legba исключает credential data и различает partial/full matches.
Сводка Nuclei не выводит raw HTTP и extracted results. В адресном превью
удаляются userinfo, query и fragment. Исходные файлы остаются в case; они
могут содержать чувствительные данные. Сводка не объявляет пустой output
доказательством завершения сканирования.

В настройках ассистента можно отключить Termux, поиск, отдельные skills
или инструменты внутри группы. Если отключить все skills, их tools исчезнут
из набора инструментов модели. TTS, Whisper и изменение skills агентом в
NetBro по умолчанию не включены; используются существующие переключатели.

## Skills и Local search

Промпт NetBro использует общую с ReBro политику: сначала профильный skill для
процедуры, затем нужные локальные проверки; для изменчивых сведений и пробелов —
Local search по официальной документации, release notes и исходникам подходящей
версии. Поиск дополняет skills. Модель выбирает действия, сопоставляет evidence
и проверяет результат. Ответы остаются на языке пользователя, обычно русском.
Уже проверенные источники и подходящие skills не перечитываются без причины.

[Политика источников и обновления](bro-skills-and-evidence.ru.md).

## Обновления и сохранение настроек

Профиль определяется стабильным ID, а не именем. Пользовательский ассистент
с именем NetBro остаётся отдельным профилем. Повторное чтение настроек не
создаёт дубликат встроенного профиля.

Ваши изменения системного промпта, модели, tools и enabled skills сохраняются
при обновлении и JSON backup/restore. Точно совпадающий прежний стандартный промпт
обновится; отредактированный вручную останется вашим. NetBro не добавляет свои skills в ReBro
или общие профили. Редактирование пакетов в мастерской использует прежние
механизмы сохранения пользовательских файлов и версий.

После изменения пакетов обновить манифесты:
~~~sh
python3 -B scripts/update_netbro_catalog.py
python3 -B -m unittest discover -s tests -p 'test_netbro_skills.py' -v
python3 -B -m unittest discover -s tests -p 'test_bro_skill_packages.py' -v
~~~

Локальные тесты выполняют helpers на синтетических файлах и процессах.
Android-тесты проверяют реальную установку полных пакетов и состав tools,
включая отключение. Эти проверки не запускают сканирование внешних целей
и не подтверждают установку всех четырёх программ на конкретном телефоне.

В 2.5.1-rebro.4 стандартный аватар NetBro — муравьед с зелёной повязкой; пользовательские аватары сохраняются. NetBro также доступен как связанный профиль подагента со своими skills, tools и workspace. [Termux workspaces и переход на release](../termux-workspaces-and-release.md).
