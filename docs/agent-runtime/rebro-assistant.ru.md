# Встроенный ассистент ReBro

После обновления ReBro появляется в списке ассистентов с аватаром муравьеда-ниндзя.
Выберите его для нового диалога. Текущий выбранный ассистент и существующие диалоги
не переключаются автоматически.

Профиль использует общую выбранную модель, включает группу **Termux** и обычный
**Local search** приложения (`enableWebSearch`). Провайдер поиска берётся из текущих
настроек. Сохраняются общие правила переключения Local/Model search: если у выбранной
модели включён её встроенный поиск, переключите режим на Local в меню поиска чата.
Новый провайдер, модель, API-ключ или глобальное разрешение не создаются.

По умолчанию подключены ровно десять навыков Rebro kit 2.3:

- `rebro-workflow`
- `rebro-environment`
- `rebro-acquire`
- `rebro-analyze`
- `rebro-patch`
- `rebro-build`
- `rebro-sign`
- `rebro-install`
- `rebro-verify`
- `rebro-frida`

Полный kit сохранён: **254 файла**, включая исходные 253 файла пакетов и дополнительный
справочник подробных правил работы. Инструкции, references, описания каталога Frida
и текст отчёта collector переведены на английский. Исполняемый код Frida, примеры
команд, trusted pins, конфигурации устройства и лицензии сохранены. Манифесты
пересчитаны для новых байтов; SHA-256 исходных ZIP и пользовательского промпта
отдельно сохранены в `app/src/main/assets/assistant-presets/rebro/provenance.json`.
Каталог указывает размеры и хеши фактически поставляемых пакетов. Архив исходного
Git-репозитория и дубликаты корневых отчётов в APK не включены.

Системный промпт теперь задаёт работу по связке **skills + Local search + локальные
свидетельства**. Профильный skill даёт процедуру и helpers; поиск дополняет её
актуальными первичными источниками под установленную версию; проверки Termux
показывают реальное состояние окружения. Модель выбирает действия и проверяет
результат, не выдавая сведения из памяти за свежую документацию.

Подробные 21 раздел прежнего промпта доступны в
`rebro-workflow/references/operating-rules.md`, загружаемом по задаче.
Инвентаризация SM-S928B / Android 16/API 36 / ARM64 / KernelSU от 2026-09-22,
полные пути и доверенные hashes Frida, bridge и binding сохранены в профильных
справочниках и config. Это датированные сведения; текущие PID, RAM, процессы
и доступность команд агент проверяет локально. Новая статья или версия upstream
не служит причиной автоматически менять работающий pinned baseline.

Навыки загружаются по задаче через `use_skill`. Полные пакеты передаются в Termux
через существующий мост; использовать нужно возвращённый `skill_root`. Рабочие
файлы и результаты остаются в отдельном case-каталоге. Существующие настройки
синхронизации и разрешение RUN_COMMAND продолжают действовать. Добавление профиля
не запускает скрипты, не устанавливает зависимости и не меняет Frida на телефоне.

ReBro не подключает общие persona-skills других встроенных ассистентов. TTS,
Whisper, skill-management и прочие группы можно включить отдельно в его настройках.
Системный промпт, tools и навыки редактируются обычным способом. Стандартный прежний
промпт обновляется только при точном совпадении его SHA-256 и ID встроенного профиля.
Пользовательские правки промпта и установленных пакетов
сохраняются; отключённые tools и skills не включаются заново.
