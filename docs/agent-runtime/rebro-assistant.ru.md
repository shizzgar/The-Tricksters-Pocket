# Встроенный ассистент ReBro

После обновления ReBro появляется в списке ассистентов с отдельным значком 🔬.
Выберите его для нового диалога. Текущий выбранный ассистент и существующие диалоги
не переключаются автоматически.

Профиль использует общую выбранную модель, включает группу **Termux** и обычный
**Local search** приложения (`enableWebSearch`). Провайдер поиска берётся из текущих
настроек. Сохраняются общие правила переключения Local/Model search: если у выбранной
модели включён её встроенный поиск, переключите режим на Local в меню поиска чата.
Новый провайдер, модель, API-ключ или глобальное разрешение не создаются.

По умолчанию подключены ровно десять навыков Rebro kit 2.3:

- `rebro-workflow`
- `rebro-environment`
- `rebro-acquire`
- `rebro-analyze`
- `rebro-patch`
- `rebro-build`
- `rebro-sign`
- `rebro-install`
- `rebro-verify`
- `rebro-frida`

Все 253 файла из `imports/*.zip` поставляются без изменения байтов: инструкции,
references, Python/JavaScript-скрипты, конфигурации, Frida Pack и его лицензия.
Манифесты каждого пакета сохранены. Каталог релиза и происхождение находятся в
`app/src/main/assets/assistant-presets/rebro/`. Архив исходного Git-репозитория и
дубликаты корневых отчётов в APK не включены.

Системный промпт сохраняет все 21 раздел приложенного пользователем промпта.
Добавлены выбор профильного навыка, получение `skill_root`, работа с текущими
tool-схемами и local search. Профиль окружения уточнён по приложенной инвентаризации
от 2026-09-22: SM-S928B, Android 16/API 36, ARM64, KernelSU/Enforcing, обнаруженные
утилиты и отдельные установки RikkaHub. Полные пути и доверенные hashes Frida,
bridge и binding сохранены. Это датированные сведения пользователя; свежая
проверка телефона при сборке APK не выполняется.

Навыки загружаются по задаче через `use_skill`. Полные пакеты передаются в Termux
через существующий мост; использовать нужно возвращённый `skill_root`. Рабочие
файлы и результаты остаются в отдельном case-каталоге. Существующие настройки
синхронизации и разрешение RUN_COMMAND продолжают действовать. Добавление профиля
не запускает скрипты, не устанавливает зависимости и не меняет Frida на телефоне.

ReBro не подключает общие persona-skills других встроенных ассистентов. TTS,
Whisper, skill-management и прочие группы можно включить отдельно в его настройках.
Системный промпт, tools и навыки редактируются обычным способом. Повторный запуск
не сбрасывает эти изменения; пользовательские правки установленных пакетов
защищены существующими правилами мастерской навыков.
