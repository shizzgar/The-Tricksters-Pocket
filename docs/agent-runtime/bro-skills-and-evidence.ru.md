# Skills, Local search и принятие решений в ReBro / NetBro

Оба профиля используют **skills и Local search совместно**. Инструкции и справочники
всех встроенных skills написаны на английском. Это язык рабочих материалов;
ассистент отвечает на языке пользователя, обычно русском.

| Источник | Для чего используется |
|---|---|
| Подключённый skill | Процедуры, скрипты, входы, проверки, восстановление после ошибок |
| Локальные инструменты | Версии и help установленных программ, реальные файлы, процессы, состояние jobs и результаты |
| Local search | Актуальная документация, release notes, исходники, совместимость и изменения практик |
| Модель | Выбор процедуры, сопоставление свидетельств, принятие решений, выполнение и проверка результата |

Для профильной задачи агент сначала читает нужный skill. Если решение зависит от
изменчивых сведений, незнакомого API/флага, требований установки или непонятной ошибки,
он дополняет процедуру поиском по первичным источникам под установленную версию.
Сниппет поисковой выдачи не считается проверенной документацией. Поиск не заменяет
skills, а сохранённая инструкция не считается безусловно актуальной для любой версии.

Текущий запрос и настройки определяют разрешённую работу. Локальные наблюдения
показывают состояние устройства; документация объясняет поведение соответствующей
версии. При расхождении агент сопоставляет дату, версию и применимость, затем проверяет
изменение небольшим содержательным тестом. Более новая версия upstream не означает,
что надо автоматически заменить рабочую установку или доверенный Frida baseline.

Подходящие уже загруженные skills и проверенные источники переиспользуются. Простой
вопрос или локальный расчёт не требует обхода всего kit и нового веб-поиска. При
отключённом skill/поиске агент учитывает конкретный пробел и продолжает ту часть
задачи, для которой достаточно доступных свидетельств.

## Что меняется после обновления

| Сохранённое состояние | Результат |
|---|---|
| ReBro или NetBro отсутствует | Добавляется соответствующий встроенный профиль |
| Промпт точно совпадает с прежним заводским | Обновляется на новый; имя, модель, skills и tools сохраняются |
| Промпт изменён вручную, даже добавлен перевод строки | Сохраняется без замены |
| Пользовательский профиль с таким же именем или копией промпта | Сохраняется как отдельный профиль |
| Встроенный пакет не редактировался | Получает обновлённые английские инструкции |
| Пакет изменён в мастерской | Пользовательская версия сохраняется |
| Skills или инструменты отключены | Остаются отключёнными |

Распознавание старого промпта использует стабильный ID профиля и SHA-256 точного
текста; оно не основано на имени или отдельных словах. Встроенный ReBro сохраняет
подробные прежние правила в `rebro-workflow/references/operating-rules.md`, а сведения
об исходном устройстве и trusted pins — в environment/frida. Эти сведения явно
помечены как датированные, их наличие не заменяет свежую проверку телефона.

Если вы специально меняли промпт и хотите перенести новую политику в свою версию,
добавьте нужные правила из [общего контракта](../../app/src/main/java/me/rerere/rikkahub/data/ai/prompts/BroEvidencePolicy.kt)
через обычное редактирование ассистента. Автоматическое обновление не перезаписывает
ваши инструкции.

## Целостность и границы проверок

ReBro содержит 10 пакетов / 254 файла, NetBro — 6 пакетов / 22 файла. Исходные
253 файла ReBro сохранены с переводом текстовых материалов и добавленным справочником;
оригинальные ZIP-хеши остаются в provenance, новые манифесты описывают адаптированные
байты. Имена некоторых старых справочников с `_RU` и `SUMMARY.ru.md` сохранены ради
совместимости ссылок, но их содержимое теперь английское.

Тесты проверяют упаковку, хеши, ссылки, сохранение настроек и состав доступных tools.
Они не измеряют качество ответов конкретной LLM и не подтверждают внешние сканеры
или Frida на физическом телефоне. Для оценки поведения полезно экспортировать
полную Trajectory конкретного рабочего диалога.
